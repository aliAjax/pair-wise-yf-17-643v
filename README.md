# hxyfront-62005 管风琴音管调音记录

源提示词编号：7

做一个给管风琴维护人员使用的音管调音记录前端项目，可以记录教堂或音乐厅名称、音栓、音管编号、音高、音分偏差、温湿度、簧片状态和维修备注。页面需要有音栓列表、调音偏差表、温湿度记录、异常音管标记和单次维护报告页。

## 管位借用流程

- **停用原管**：在「管位借用」页登记送修去向与同音高替代管，原管标记为送修中，替代管装上管位。
- **测量跟随当前管**：调音记录与异常判断（音分偏差超过 ±8 cent）都记在测量时实际安装的管名下，不再混入原管台账。
- **回装 / 撤走**：原管回装或替代管撤走时，仅该管位的调音结论转为「待复核」，其他管位结论照常保留。
- **单次维护报告**：按测量日期生成，每行同时列出管位、当前安装管和该管位原管的送修前旧值，便于回装后对照。
- **数据只存浏览器**：全部台账保存在 localStorage，不上传服务器；「重置示例数据」可还原初始样例。
