# hxyfront-62005 管风琴音管调音记录

给管风琴维护人员使用的音管调音记录前端：记录场馆名称、音栓、音管编号、音高、音分偏差、温湿度、簧片状态和维修备注，并支持开裂音管送修期间的「管位借用」流程。

## 管位借用流程

- **送修登记（停用原管）**：在「音栓与管位」对在装原管登记送修去向、原因与同音高替代管；原管置为「送修中」，替代管立即上位，系统自动锁定原管送修前最后一次测量作为**送修前旧值**。
- **测量跟随当前管**：新增测量一律记入当时实际安装的音管名下（管位与音管两个维度同时保存），异常判断与管位调音结论只依据「当前安装管在本次安装之后」的测量，原管/备用管的历史结果互不串用。
- **原管回装 / 撤走替代管**：只把该管位的调音结论置为「待复核」，替代管撤回备用库存；其他管位结论照常保留。对当前管复测后结论自动恢复为正常/异常。
- **单次维护报告**：按管位生成，同时给出管位（场馆/音栓/管位号/音高）、当前安装管、送修前旧值、借用时间线及本管位按音管归属的测量台账，可直接打印。
- **数据只存浏览器**：全部数据保存在 `localStorage`（键名 `hxyfront-62005:organ-state:v1`），无后端；可一键重置为演示数据。

## 页面

音栓与管位（送修登记 / 原管回装 / 撤走替代管 / 安装音管）、调音测量（调音偏差表、温湿度记录）、借用台账（进行中 + 历史）、异常音管标记（当前异常、待复核、历史异常）、单次维护报告。
